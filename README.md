# SmartEdge

Fast • Secure • Smart Payments & Business Management Platform.

## 🚀 Features

- **Lead & Sales Landing Page (`index.html`)**: Modern high-converting login and landing interface with responsive layout, 3D hero graphics, and authentication flow.
- **Business Dashboard (`dashboard.html`)**: Full-featured fintech dashboard with:
  - Real-time Wallet Balances (Wallet Balance, AEPS Wallet, Commission) with mask/unmask privacy toggle.
  - Quick Actions tiles for instant services (Money Transfer, BizPPI, Flight Booking, Recharges, etc.).
  - Interactive SmartEdge promo card with angled 3D device showcase.
  - Last 10 Transactions table with live search and status indicators.
  - Business Summary with responsive upward trend charts and daily activity breakdown.
  - Phosphor Duotone & Bold modern icon system.
  - 100% Mobile and tablet responsive with off-canvas slide-out sidebar drawer.

## 🛠️ Tech Stack

- HTML5 & CSS3
- Tailwind CSS
- Phosphor Icons & Remix Icon
- Google Fonts (Plus Jakarta Sans & Inter)
